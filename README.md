# 실력 대결 — 1:1 듀얼

운도 성장 요소도 없는, 오직 실력으로만 싸우는 1:1 사격 듀얼. 설치 없이 브라우저에서 바로 플레이 (PC·모바일).

▶ **플레이:** `https://<내아이디>.github.io/<저장소이름>/`

## 모드
- **온라인 대결** — 방장이 방을 만들고 5자리 코드를 친구에게 전달 → 친구가 "방 입장"에서 입력
- **로컬 대결** — 한 화면에서 2인
- **봇 연습** — 혼자서 (쉬움/보통/어려움)

## 조작 (PC)
| | 1P / 온라인 | 2P(로컬) |
|---|---|---|
| 이동·조준 | WASD (또는 방향키) | 방향키 |
| 점프 / 사격 / 대시 | F / G / H | . / / / , |
| 패링 / EX / 조준고정 | Q / T / R | L / ' / ; |

모바일은 화면 터치 버튼 (왼쪽 가상 스틱).

## 규칙
HP 100, 3판 2선승(5판 3선승 선택), 라운드 60초. 패링: 상대 탄이 닿는 순간 눌러 되돌리기(EX 탄 불가, 헛치면 무방비). EX는 때리거나 맞으면 차오르는 관통탄.
랜덤 없음 · 양쪽 조건 완전 대칭 · 락스텝 동기화로 방장 유리 없음.

## GitHub에 올리는 법
1. GitHub에서 새 저장소 생성 (Public)
2. 이 폴더의 파일을 전부 업로드 (`.github` 폴더 포함 — 웹에서는 "Add file → Upload files"로 폴더째 끌어다 놓기)
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**
4. Actions 탭에서 "Deploy to GitHub Pages"가 초록색이 되면 위 주소로 접속

> 워크플로 없이 쓰려면 Source를 "Deploy from a branch (main /root)"로 두면 돼요. 이 경우 PeerJS는 CDN에서 불러옵니다.

## 온라인 대전 참고
- 서버 없이 WebRTC(P2P)로 연결해요. 방 코드 중계는 PeerJS 공개 서버를 사용합니다.
- 일부 회사·학교·모바일 통신망(엄격한 NAT)에서는 직접 연결이 안 될 수 있어요. 그땐 다른 네트워크(Wi-Fi ↔ 데이터)로 바꿔 보세요.
- 두 사람 모두 같은 버전이어야 해요 (다르면 안내 표시 → Ctrl+F5).
